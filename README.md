## 📂 Projects Included

### 1. Movie Recommendation System
**File:** `Recommender.py`

A movie recommendation system that suggests movies based on genre similarities and user preferences.

**Features:**
- Content-Based Filtering.
- Collaborative Filtering (User-Based).
- TF-IDF Vectorization.
- Cosine Similarity.
- Movie recommendations based on similar genres.
- User preference-based recommendations.

**Technologies Used:**
- Python
- Pandas
- NumPy
- Scikit-learn

**Installation:**
```bash
pip install pandas numpy scikit-learn
```

**Run the project:**
```bash
python Recommender.py
```

### 2. Rule-Based Chatbot
**File:** `rule_based_chatbot.py`

A simple interactive chatbot developed using Python. It uses predefined rules, conditional logic, and regular expression pattern matching to understand user inputs and generate appropriate responses.

**Features:**
- Responds to greetings.
- Recognizes user names.
- Provides current date and time.
- Performs simple mathematical addition.
- Tells random jokes.
- Responds to common questions.
- Handles conversation-ending commands.

**Technologies Used:**
- Python
- Regular Expressions (re)
- Random Module
- Datetime Module

**Run the project:**
```bash
python rule_based_chatbot.py
```

### 3. Tic-Tac-Toe AI
**File:** `tic_tac_toe_ai.py`

An AI-powered Tic-Tac-Toe game where a human player competes against an intelligent computer opponent.

The AI uses the Minimax algorithm with Alpha-Beta Pruning to evaluate possible moves and select optimal decisions.

**Features:**
- Interactive two-player-style gameplay against AI.
- Intelligent computer opponent.
- Minimax algorithm.
- Alpha-Beta Pruning.
- Win, lose, and draw detection.
- Optimal move selection.

**Technologies Used:**
- Python
- Minimax Algorithm
- Alpha-Beta Pruning
- Math Module

**Run the project:**
```bash
python tic_tac_toe_ai.py
```
